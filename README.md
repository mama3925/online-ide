# onlineIDE

## *具体功能与介绍请查看README.en.md*

## 项目简介

这是一个在线集成开发环境（Online IDE）项目，目前正在初始化中。目标是做成一个轻量级vscode在线版。

## 当前状态

本项目正处于起始阶段，目前正在ui阶段，暂不考虑鉴权与并发。

## 技术栈

前后端不分离，前端采用next.js，后端用nextjs的api路由和服务端组件。
编辑器使用Monaco Editor组件
智能体部分借助langchain框架进行工作流编排

## 快速开始

```bash
# 克隆项目
git clone https://gitee.com/mama3925/onlineIDE.git

# 进入项目目录
cd onlineIDE
```

## 功能规划

- 在线代码编辑
- 代码运行与调试
- 项目文件管理
- 多人协作支持
- 模型接口调用
- 简易智能体

（更多功能待完善）
