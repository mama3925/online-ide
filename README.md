这是一个在线集成开发环境（Online IDE）项目，目前正在初始化中。

本项目正处于起始阶段，仅包含基本的项目配置文件。

## 快速开始

```bash
# 克隆项目
git clone https://gitee.com/mama3925/onlineIDE.git

# 进入项目目录
cd onlineIDE
```
